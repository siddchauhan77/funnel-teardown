Journey: inspect the conceptual funnel, choose a question, inspect actual report evidence, understand report outputs, understand the agent process, install or return to the selected evidence. Energy: compact object opening, strongest report reveal, quiet awareness legend, crisp feature entrance, one process headline resolution, usable close. Feeling: curiosity → control → confidence → understanding → readiness. Peak: the abstract funnel gives way to the actual AG1 report at the selected section. Tell-someone: I pull apart the funnel, then inspect the exact report section I care about. Signature: a tactile layer-separation control followed by a report lens which carries to the full report and closing link. Range: technical exhibit rather than continuous film. Assets: existing real AG1 HTML report and semantic CSS funnel geometry. No generated graphics, fake dashboards, invented client results, or added API calls.

## Grammar and score
Four families, separated by their purpose:
1. Parallax. Independently moving conceptual funnel slices, rear axis, foreground thread, stable semantic copy.
2. Reveal. The actual report window opens into view. Coverage, Journey and Open questions controls navigate real report anchors. The selector does not pretend to run fresh analysis.
3. Entrance. The feature grid arrives after the still awareness legend.
4. Kinetic. A single process heading resolves while the four real pipeline stages remain readable.
5. Native close. Existing installation instructions, a copy-install action, and a link back to the user's selected evidence. No artificial hold or pinning.
The report is the visual peak. The primary CTA opens it immediately. The hero is shortened to four text groups. Existing unsupported per-run-price copy is not promoted in the new opening. The report's seven journey labels are described without attributing all seven to Schwartz's original framework.
